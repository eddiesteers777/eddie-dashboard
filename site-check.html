Site Check

Runs the same checks I've been doing by hand throughout this project — real syntax parsing, import/export cross-referencing, broken DOM references, dead nav links, orphaned files, and cloud-sync coverage — directly in your browser against the live files on this domain.

Run this after pushing to GitHub Pages, not by double-clicking the file on your computer — browsers block a local file from fetching its sibling files for security reasons, so this only works once it's actually being served from a real address (your GitHub Pages URL, or a local dev server). The file list below is hand-maintained near the top of this file's script — add new pages/files there if you create them, or this can't see them.
