# Brainstorm

`/brainstorm [topic]` turns the session into a talking session for ideas.

- **Each round:** 3 variations, 1 pushback, 1 question. Short and plain.
- **Steering:** every third round (or type `steer`) a short recap, what to drop, and two directions with a recommendation.
- **Panel:** type `panel` and three helpers answer at once (coach, athlete, skeptic; teacher, student, parent for school topics). Only costs extra when you ask.
- **Other words:** `more`, `deeper 2`, `keep 2`, `drop 3`.
- **Wrap:** type `wrap`. Your picks go into QUEUE.md under NEXT or HELD. No threads or builds start from it.

It builds nothing and merges nothing while on.

## Install

```
/plugin marketplace add eddiesteers777/eddie-dashboard
/plugin install brainstorm@southbound-tools
```
Sessions on this repo get it automatically once merged (`.claude/settings.json`).
